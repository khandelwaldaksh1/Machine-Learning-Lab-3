# ML Lab-3: Find-S and Candidate Elimination

## Aim
To implement Find-S and Candidate Elimination Algorithms on the Enjoy Sports dataset and compare the generated hypotheses.

## Objective
To understand concept learning using Find-S and Candidate Elimination algorithms and analyze the hypotheses generated from training examples.

## Dataset
The practical uses the Enjoy Sports dataset.

### Attributes
- Sky
- AirTemp
- Humidity
- Wind
- Water
- Forecast
- EnjoySport

## Algorithms Implemented

### 1. Find-S Algorithm
Find-S finds the most specific hypothesis consistent with the positive training examples.

### 2. Candidate Elimination Algorithm
Candidate Elimination maintains the Specific Boundary (S) and General Boundary (G) while processing the training examples.
